# Codex 自动调用 Copilot Worker 设计

## 1. 目标

在 Codex 主智能体中自动识别低复杂度任务，并通过已登录的 GitHub
Copilot CLI 执行这些任务。Copilot 固定使用 `auto` 模型选择，不指定具体模型。
Codex 保留任务路由、结果审查、验证和最终交付职责。

第一版允许 Copilot：

- 读取和修改当前工作区文件；
- 运行 Shell 命令；
- 访问外网；
- 使用当前用户已登录的 Copilot Student 权益。

第一版不使用 `copilot-api`、协议反向代理或 Codex 自定义模型 provider。

## 2. 路由边界

Codex 可以自动分配以下低复杂度任务：

- 文件搜索、内容摘要和日志归类；
- 格式整理、机械重命名和明确的批量替换；
- 需求清晰、局部且容易验证的小函数；
- 测试样板和文档更新；
- 运行已有检查并总结结果。

以下任务由 Codex 自己处理，不自动交给 Copilot：

- 架构设计、模糊需求和跨模块决策；
- 安全、权限、凭证和隐私相关修改；
- 删除、覆盖、发布、部署及其他不可逆操作；
- 需要高风险外部写操作的任务；
- Copilot 结果的评审、修正和最终验收。

当任务是否简单存在明显歧义时，Codex 不自动委派。

## 3. 执行架构

采用单写者顺序执行：

1. Codex 判断任务是否满足自动委派条件。
2. Codex 调用项目内的 Copilot worker，并在 worker 运行期间停止自身文件编辑。
3. worker 获取项目级独占文件锁。
4. worker 使用非交互方式调用 Copilot CLI，并显式传入 `--model auto`。
5. Copilot 完成后，worker 返回退出状态、标准输出和标准错误摘要并释放锁。
6. Codex 检查工作区变化，运行与变更相称的验证，必要时修正。
7. Codex 向用户交付最终结果；Copilot 的输出不能直接视为完成证明。

同一工作区内的所有 Copilot worker 调用共用一把锁。锁只协调遵循该协议的
Codex/Copilot worker，不阻止用户或其他外部进程同时修改文件。

## 4. 组件

### 4.1 Worker

项目内提供一个 Python 命令行程序，职责仅包括：

- 接收任务文本；
- 定位工作区根目录；
- 获取和释放独占锁；
- 构造固定使用 `auto` 的 Copilot CLI 命令；
- 以当前工作区为工作目录运行 Copilot；
- 透传可审计的输出和退出码；
- 在 CLI 缺失、未登录、锁占用、超时或 Copilot 失败时给出明确错误。

worker 不保存或打印 GitHub Token，不自行实现登录，也不调用逆向代理。

### 4.2 项目级 Codex Skill

项目级 skill 说明：

- 哪些任务应自动委派；
- 哪些任务禁止自动委派；
- 如何调用 worker；
- worker 运行期间 Codex 必须保持单写者状态；
- worker 返回后必须进行独立检查和验证。

### 4.3 `AGENTS.md` 路由规则

在现有 `AGENTS.md` 中加入最小规则，使后续 Codex 会话能发现并自动使用该
worker。规则不得改变现有音视频评测数据隔离、CSV schema 或生成物约束。

## 5. 权限与安全

Copilot 可以修改工作区、运行 Shell 和访问外网，但仍受以下约束：

- 工作目录固定为当前项目；
- 不向提示词或日志注入、输出任何凭证；
- 不使用 `--allow-all-paths` 扩展到项目外部；
- 不自动执行删除、发布、部署、提交或推送；
- 非交互调用关闭不必要的远程会话导出；
- 继承并遵守项目 `AGENTS.md`；
- Codex 对所有修改承担最终审查责任。

如果 Copilot 因非交互权限不足而无法完成任务，worker 返回失败；不得在未记录的
情况下静默扩大权限。

## 6. 错误处理

- `copilot` 不存在：立即失败并提示安装检查。
- 登录或额度不可用：保留 Copilot 原始错误摘要并失败。
- 锁已被占用：等待至配置的超时；超时后失败，不启动第二个 writer。
- Copilot 超时：终止子进程、释放锁并返回超时状态。
- Copilot 返回非零状态：不宣称任务完成，由 Codex检查是否产生部分修改。
- Codex 验证失败：由 Codex 修正或向用户报告，不能用 Copilot 的成功输出覆盖
  实际验证结果。

## 7. 测试与验收

自动化测试使用假的 `copilot` 可执行程序，不消耗学生额度，并覆盖：

- 命令固定包含 `--model auto`；
- 工作目录正确；
- 成功时透传输出和零退出码；
- Copilot 非零退出时正确失败；
- 并发调用不能同时进入执行区；
- 超时后释放锁；
- 命令不包含 `--allow-all-paths`；
- 日志不主动输出凭证。

完成自动化测试后，进行一次真实只读探针：

- 让 Copilot 使用 `auto` 总结项目顶层用途；
- 不允许该探针修改文件；
- 验证成功登录、实际返回内容和退出状态。

随后进行一次受控写入探针：

- 仅修改一个专用临时测试文件；
- Codex 等待 Copilot 完成后检查文件内容；
- 清理测试文件前先确认它确由探针创建。

验收通过的条件：

- Codex 能依据路由规则自动选择 worker；
- Copilot CLI 的真实调用使用 `auto`；
- 同一时间最多一个 Copilot writer；
- 真实探针成功，且没有未授权的项目文件变化；
- Codex 能独立验证并报告 Copilot 的结果。

## 8. 非目标

第一版不实现：

- Copilot 私有接口反向代理；
- 将 Copilot 注册成 Codex 原生模型 provider；
- 多个 Copilot writer 并行修改同一工作区；
- 跨项目全局安装；
- 自动提交、推送、发布或部署；
- 绕过 Copilot 额度、模型或账号限制。
